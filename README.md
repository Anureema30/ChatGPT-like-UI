🤖 ChatGPT-like UI using Streamlit with Ollama Backend and OCR Integration

🎯 Project Objective

To build a "ChatGPT-like conversational interface" using Streamlit, powered by Ollama as the backend large language model (LLM), with integrated OCR (Optical Character Recognition)** to extract text from uploaded images or PDFs. The goal is to create a local, privacy-friendly, and interactive chatbot that can understand both text and image-based inputs.


✨ Key Features

💬 Chat Interface: Modern, Streamlit-based UI for smooth conversation flow.
🧠 Ollama Backend: Local LLM inference for privacy and low latency.
🖼️ OCR Integration: Extract text from images or PDFs using Tesseract or EasyOCR.
📁 File Upload Support: Upload images or PDFs for OCR processing.
🧾 Conversation Memory: Maintains session context between user and assistant.
⚙️ Configurable System Prompts: Customize the assistant’s behavior easily.
🔒 Local-First Design: All processing happens locally for maximum privacy.


🧰 Tech Stack Used                                        

🖥️ Frontend:- Streamlit                                           
🧠 LLM Backend:- Ollama (LLaMA2 or compatible models)                
🔍 OCR Engine:- Tesseract OCR / EasyOCR                             
🐍 Language:- Python 3.10+                                        
📄 Dependencies:- requests, pillow, pytesseract, pdf2image, streamlit 
                       

🚀 Outcome

A functional and extensible AI chat assistant that:

Reads both text and visual inputs🖼️
Runs entirely on local hardware💻
Can be extended for custom models, OCR improvements, or advanced prompts
